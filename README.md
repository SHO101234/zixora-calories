# ကယ်လိုရီ — Thadingyut Calorie App

Android app (မြန်မာလို UI အပြည့်အစုံ) — တစ်နေ့တာ စားတဲ့ အစားအစာတွေကို ထည့်ပြီး ကယ်လိုရီ တွက်ပေးတယ်။
ပန်းတိုင် (ဝိတ်လျော့မလား၊ ထိန်းမလား၊ တင်မလား) ပေါ်မူတည်ပြီး တစ်ရက်ကို ဘယ်လောက် စားသင့်လဲ တွက်ပေးတယ်။

## အဓိက အချက်များ
- **Offline အပြည့်အဝ** — အင်တာနက် လုံးဝ မလိုဘူး၊ အကောင့် မလိုဘူး၊ server မရှိဘူး။ ဒေတာအားလုံး ဖုန်းထဲမှာပဲ သိမ်းတယ် (SharedPreferences)။ App မှာ INTERNET permission တောင် မပါဘူး။
- **အစားအစာ ထည့်နည်း ၂ မျိုး**
  1. **ပုံမှန်ပွဲ (ချိန်စရာ မလိုဘူး — ပုံသေ)** — လက်ဖက်ရည် ၁ ခွက်၊ နန်းကြီးသုပ် ၁ ပွဲ၊ အီကြာကွေး ၁ ချောင်း စတဲ့ လက်ဖက်ရည်ဆိုင် / လမ်းဘေး အစားအစာတွေကို အရေအတွက်ပဲ နှိပ်ထည့်ရုံနဲ့ ရတယ်။ အလေးချိန် သိစရာ မလိုဘူး။
  2. **အလေးချိန်နဲ့ (ပိုတိကျချင်ရင် — ရွေးချယ်ခွင့်)** — အိမ်မှာ ချက်တဲ့ အစားအစာတွေကို ဂရမ်နဲ့ ချိန်ပြီး၊ ၁၀၀ ဂရမ်မှာ ကယ်လိုရီ ဘယ်လောက် ပါလဲ ထည့်ရင် ပိုတိကျတယ်။ ချိန်တာ မလိုအပ်ဘူး၊ လိုချင်မှသာ သုံးပါ။
- **တွက်နည်း — Mifflin-St Jeor (ဆေးဘက်ဆိုင်ရာ စံပြ)** — အာဟာရပညာရှင်တွေ သုံးတဲ့ စံပြ formula နဲ့ BMR တွက်ပြီး၊ လှုပ်ရှားမှု အဆင့်နဲ့ မြှောက်ပြီး TDEE ရတယ်။ ပြီးရင် ပန်းတိုင်အတိုင်း −၅၀၀ / အတိုင်း / +၃၀၀ လုပ်တယ်။ Formula ကို app ထဲမှာ မြန်မာလို အတိအကျ ပြထားတယ်။
- **တိကျမှုအကြောင်း ရိုးသားစွာ** — formula က စံပြ ဖြစ်ပေမယ့် ရလဒ် တိကျဖို့က သုံးစွဲသူ ထည့်တဲ့ အရပ် / ကိုယ်အလေးချိန် / လှုပ်ရှားမှု မှန်ဖို့နဲ့၊ အစားအစာကို တိတိကျကျ ထည့်ဖို့ လိုတယ်။ တစ်ယောက်ချင်းစီရဲ့ ဇီဝကမ္မနဲ့ ချက်ပြုတ်နည်းပေါ်မူတည်ပြီး ကွာနိုင်တယ်၊ ဓာတ်ခွဲခန်း တိုင်းတာမှ ၁၀၀% တိကျမယ်။ ဆီးချို၊ ကျောက်ကပ်၊ ကိုယ်ဝန်၊ အစားအသောက် ရောဂါ၊ ဆေးသောက်နေရင် ဆရာဝန်နဲ့ တိုင်ပင်ပြီး ပန်းတိုင်ကို ဆရာဝန်သတ်မှတ်တာနဲ့ သုံးပါ။

## အစားအစာ စာရင်း (ခန့်မှန်းခြေ)
Built-in စာရင်းထဲက ကယ်လိုရီတွေဟာ ထုတ်ပြန်ထားတဲ့ စံ ခန့်မှန်းခြေတွေပါ — ဓာတ်ခွဲခန်း တိုင်းတာချက် အတိအကျ မဟုတ်ဘူး။ ဆိုင်တစ်ဆိုင်နဲ့ တစ်ဆိုင်၊ ချက်နည်းပေါ်မူတည်ပြီး ကွာနိုင်တယ်။ နေ့စဉ် ခြေရာခံဖို့ လုံလောက်တဲ့ တိကျမှုရှိတယ်၊ ပိုတိကျချင်ရင် အလေးချိန်နဲ့ ထည့်ပါ။

## ဆောက်နည်း
- Local (Gradle ရှိတဲ့ စက်မှာ): `gradle assembleDebug` — APK: `app/build/outputs/apk/debug/app-debug.apk` (debug-signed, စမ်းသပ်ဖို့သာ)
- GitHub Actions: `.github/workflows/build.yml` (setup-java 17 + setup-gradle 8.5 → `gradle assembleDebug` → artifact `calorie-app-debug`) — repo ကို push လုပ်ပြီးမှ run တယ်၊ ဒီ task မှာ push မလုပ်ထားဘူး။

## စမ်းသပ်နည်း (ဖုန်းမှာ)
1. APK ကို ဖုန်းမှာ install လုပ်ပါ။
2. "ကိုယ်ရေးအချက်အလက်" ကို ဖွင့်ပြီး ကျား/မ၊ အသက်၊ အရပ်၊ ကိုယ်အလေးချိန်၊ လှုပ်ရှားမှု၊ ပန်းတိုင်ကို ထည့်ပြီး သိမ်းပါ။
3. ပင်မစာမျက်နှာမှာ ပန်းတိုင် ကယ်လိုရီ ပေါ်လာမယ်။
4. အစားအစာ ထည့်ကြည့်ပါ — ပုံမှန်ပွဲရော၊ အလေးချိန်နဲ့ရော။
5. "လမ်းညွှန်" ကို ဖတ်ကြည့်ပါ — အကုန် မြန်မာလိုပါ။
